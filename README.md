# 📚 NoteVerse

> An AI-powered collaborative study platform that enables students to learn together through AI assistance, real-time collaboration, quizzes, flashcards, and productivity tools.

---

## 🚀 Introduction

NoteVerse is a modern collaborative learning platform that combines Artificial Intelligence with interactive study tools to create a smarter learning experience. It helps students study individually or in groups using AI-powered assistance, collaborative workspaces, and productivity features—all within a single application.

---

## 🛠️ Technologies

| Category | Technologies |
|----------|--------------|
| **Frontend** | Next.js, React, TypeScript, Tailwind CSS |
| **Backend** | Firebase Authentication, Firestore |
| **AI** | Google Gemini API |
| **Storage** | Vercel Blob Storage |
| **Deployment** | Vercel |

---

## ✨ Features

- 🤖 AI Study Assistant
- 💬 AI Chat
- 📝 AI Quiz Generator
- 🧠 AI Flashcard Generator
- 🎨 Collaborative Whiteboard
- 👥 Shared Study Rooms
- ⏱️ Pomodoro Focus Timer
- 🔒 Secure Firebase Authentication
- 📱 Responsive Design
- ⚡ Fast and Modern User Experience

---

## ⚙️ Process

1. Users sign in securely using Firebase Authentication.
2. Create or join collaborative study rooms.
3. Interact with the AI assistant for instant learning support.
4. Generate quizzes and flashcards using AI.
5. Collaborate with others through the shared whiteboard.
6. Stay focused using the integrated Pomodoro timer.

## 🚀 Running the Project

1. **Clone the repository**

```bash
git clone https://github.com/yourusername/noteverse.git
```

2. **Navigate to the project**

```bash
cd noteverse
```

3. **Install dependencies**

```bash
npm install
```

4. **Add your environment variables** to a `.env.local` file.

5. **Start the development server**

```bash
npm run dev
```

Open **http://localhost:3000** in your browser.
